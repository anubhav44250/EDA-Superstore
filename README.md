Tools: Pandas, Matplotlib, Seaborn  
Dataset: Superstore Sales  


Project Description

This project performs Exploratory Data Analysis (EDA) on a retail Superstore dataset to understand sales patterns, profitability, and category performance. Using Python libraries such as Pandas, Matplotlib, and Seaborn, the dataset was cleaned, visualized, and analyzed to identify trends, correlations, and business insights.

The analysis focuses on understanding distribution of sales and profit, impact of discounts on profitability, regional performance differences, and relationships between key variables. The goal of this project is to demonstrate practical data analysis skills and the ability to extract meaningful insights from real-world business data.
